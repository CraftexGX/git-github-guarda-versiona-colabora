# Git y GitHub: Guarda, Versiona, Colabora

## Descripción del proyecto

Repositorio del Examen Práctico 2. Aquí practicamos el control de versiones con Git y GitHub:
creamos un repositorio, registramos cambios con commits, los subimos a GitHub y colaboramos
en equipo sobre una página web sencilla (`index.html`) con la información de los integrantes.

## Objetivo

Comprender y aplicar los conceptos básicos del control de versiones con Git y GitHub para
gestionar cambios y desarrollar actividades colaborativas.

## Comandos básicos

| Comando | Para qué sirve |
|---|---|
| `git init` | Crea un repositorio Git nuevo en la carpeta actual. |
| `git add` | Agrega los cambios de los archivos al área de preparación (staging) para el próximo commit. |
| `git commit` | Guarda en el historial una "foto" de los cambios preparados, con un mensaje que los describe. |
| `git status` | Muestra qué archivos cambiaron, cuáles están preparados y cuáles no. |
| `git log` | Muestra el historial de commits del repositorio. |
| `git push` | Envía los commits locales al repositorio remoto en GitHub. |
